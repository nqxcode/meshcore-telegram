# Применение ub-mode

Дата: 29 октября 2026 года.

## Результаты

| Проверка | До изменений | После изменений |
| --- | --- | --- |
| Unit-тесты | 35 | 73, все проходят |
| Покрытие строк | 69% двух модулей моста; скрипт настройки не исполнялся | 99% трёх production-модулей |
| Максимальный CRAP функции | 51,1 | 7,0; все функции ниже 10 |
| Кандидаты dryer при пороге 0,8 | 0 | 0 |
| Мутации | 75 уничтожены, 41 выжила, 43 непокрытых места | 158 уничтожены, 0 выживших, 0 непроверенных мест |

В финальном измерении покрытия не исполнены только три блока запуска
`if __name__ == "__main__"`. Функции запуска проверяются через их публичные
точки входа с имитациями внешних зависимостей. Мутационный результат относится
к операторам, поддерживаемым установленным mutator, и не доказывает отсутствие
всех возможных ошибок.

## Журнал действий и причин

1. Проверены исходные тесты и выбран `.meshcore-venv`: старое окружение `.venv`
   не содержит MeshCore. Установлен coverage как зависимость разработки.
2. Измерены исходные покрытие, CRAP и мутации. Выявлены непроверенные сценарии
   запуска, ошибки внешних интерфейсов и недостаточно точные проверки границ.
3. Добавлены тесты HTTP-ошибок Telegram, загрузки состояния, подключения и
   отключения Companion, фонового event loop, тайм-аутов, параметров настройки
   устройства и восстановления циклов опроса. Внешние обращения заменены
   имитациями, рабочий сервис не перезапускался.
4. Поведение обработчиков закреплено тестами. Затем из крупных функций выделены
   разбор сообщения, справочные команды, подготовка текста, сохранение попытки,
   отправка, дедупликация пакета и группировка списка узлов. Разбор адресации
   команд используется обоими мостами. Порядок сохранения до отправки сохранён.
5. Два новых теста сначала воспроизвели ошибки ограничения частоты: первая
   попытка зависела от нулевой точки часов, а сообщение об ожидании завышало
   целое число секунд. Исправлены исходное значение времени предыдущей попытки
   и округление ожидания через `ceil`; оба теста прошли.
6. Убрана недостижимая проверка пустой второй части команды после `split`.
   Добавлены проверки точной вместимости кэша, удаления старейшей записи,
   истечения времени, размера страниц, одинаковых имён узлов и выбора канала.
7. Повторно измерены CRAP и дублирование. Все функции прошли порог CRAP,
   кандидатов на дублирование нет. Полный мутационный прогон без фильтра LCOV
   сначала оставил три мутации; тесты очереди из нескольких Telegram updates
   и одинаковых имён узлов были усилены, после чего уничтожены все 158 мутаций.
8. Зависимость coverage закреплена в `requirements-dev.txt`; команды проверок
   описаны в README. Локальные инструменты и отчёты исключены из Git.

Тесты межпоточного event loop выполнялись вне ограниченной песочницы: внутри
не срабатывало пробуждение event loop через `run_coroutine_threadsafe`.
Самостоятельный минимальный пример воспроизвёл ограничение; при запуске вне
песочницы те же тесты проходят.

Команды для повторения проверок приведены в разделе «Проверки» README.
Машинные отчёты сохраняются локально в `.metrics/` и `target/coverage/python/`.
